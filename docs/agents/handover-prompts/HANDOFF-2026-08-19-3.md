## Completed Checkpoint - #53 Typed Causes (`28d09e1`)

- `x-effect-stream` is no longer opaque JSON. Its encoding, failure event, cause schema, and error
  schema survive typed ingestion into SpecIR.
- Exact standalone `not: {}` projects as `NeverNode`; other `not` forms refuse at the applicator
  pointer. The implementation does not claim general JSON Schema negation.
- Generic inhabitation analysis makes an object with a required never member impossible. The pin's
  `Fail.error` therefore makes `Fail` uninhabitable without endpoint or tag-specific machinery.
- The public cause union contains `StreamFailureCauseDie`, `StreamFailureCauseInterrupt`, and
  `UnknownStreamFailureCause`. No dead `StreamFailureCauseFail` type is emitted.
- The generated converter retains the declared `Fail` tag as known-impossible and refuses it as a
  protocol error. Only genuinely unrecognized tags use ADR-0009's unknown carrier.
- Cause interfaces, variants, converter, unknown carrier, array metadata, stream adapter metadata,
  registry entries, and System.Text.Json source generation pass through one bound/emitted compile
  chain without reflection fallback.
- A valid reserved failure frame throws `OpenCodeStreamFailureException`, preserving the existing
  `OpenCodeTransportException` catch hierarchy and exposing typed reasons through `Cause`.
  Malformed, null, or known-impossible causes remain base transport/protocol failures.
- Ordinary payloads, undeclared event names, cancellation, lazy opening, disposal, and lifecycle
  behavior remain unchanged.
- The selected profile remains 14 operations. No `event.subscribe`, #44 naming work, Arc 3b breadth,
  #49 plural membership, or 40/87 fixture corpus entered the increment.

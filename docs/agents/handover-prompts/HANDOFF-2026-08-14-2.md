## Work Queue (in this order)

### A. Alignment batch — on this branch, into PR #26

**A1 — Uniform `*Request` rename (Q83).** Every operation input becomes
`{Group}{Subject}{Verb}Request`; the Options family retires.

- Hand-written spine: `ListOptions.cs` → `ListRequest.cs` (abstract record, same
  Limit/Order/Cursor trio — the M3 paginator seam keeps its shape under the new name).
  `ListOrder`, `ListCursor`, `SessionParentFilter` unchanged.
- Generator: `OperationNamePolicy.OptionsTypeName` retires; query records derive through
  `RequestTypeName`. **Deliberate consequence:** an operation declaring both a body and
  query parameters derives the same type name twice and fails the existing collision
  wall — the intended fail-closed state until a merged-Request design (one Request
  carrying both, AWS-marshalling style) is sealed. Pin that in a refusal test.
- Internal vocabulary (`OperationOptionsPlan`, `OptionsPropertyPlan`, `OptionsEmitter`,
  `OperationPlan.Options`) may rename to `Query*`/`*Request*` — internal taste; pick one
  scheme, be consistent.
- Signatures: method and route-builder parameter `options` → `request`;
  `requestOptions` unchanged. Update `ReservedParameterNames` to emitted reality
  (`request`, `requestOptions`, `cancellationToken`, `pipeline`).
- Same-sweep fallout: regen, all emitter snapshots re-verify, PublicApi baseline
  (rename-only diff — review as such), contract tests, `ListMessagesAsync` benchmark,
  sandbox program, ROADMAP wording ("`ListOptions` seam" → `ListRequest`). The research
  log stays untouched (dated history). Perf-neutral — no benchmark re-run.

## Session Mechanics The Docs Don't Carry

- Dev loop: all six gates before every commit, chained under `set -o pipefail` with an
  explicit ALL-GREEN marker; commit per green increment; push on the working branch is
  authorized; red-test-first is demanded.
- **Decisions to the maintainer go as plain text in chat — never AskUserQuestion
  dialogs** (option-dialog annotations have been lost in transit; the maintainer
  rejected the flow). Batch them with a recommendation; engage their notes in prose
  before touching code — jumping to implementation mid-discussion is a standing
  complaint.
- Regen ritual: edit emitters → `dotnet run --file tools/opencode-tool.cs -- generate`
  → review the git diff of committed output → snapshot received→verified after review →
  `generate --verify` must be a byte-identical no-op before commit.
- The PublicApi baseline diff is maintainer review surface, never auto-accepted
  silently.
- Multi-TFM traps are already paid for — see the agent memory and the test csproj
  comments before rediscovering them.

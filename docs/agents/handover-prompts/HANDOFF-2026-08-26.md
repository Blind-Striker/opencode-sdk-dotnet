## Doc 21 is the critical read

It measures what the OpenAPI document does not carry, anchored to two fixed points — the pin
`a6a712a3` and the `v2` tip — plus a third artifact, **TIP+RESTORE**: the tip with our offered
upstream patch applied. Its shape:

- **§2 negative results** — endpoint parity is exact (131 = 131, zero drift, mechanism
  verified), declared channels project faithfully (zero parameter or status mismatches), and
  our fail-closed walls independently match upstream's own codegen exclusions. These close
  questions; do not reopen them without new evidence.
- **§3.1 our gaps** — no per-request header channel (which makes `PostConnectTokenAsync`
  unusable and also blocks the `x-opencode-directory` multi-project targeting recorded in doc 01
  §4); the envelope binder accepting only `data: $ref`; undeduplicated error unions; a
  diagnostic that reports a missing *name* as a failed promotion; an alias guard that cannot
  separate identically-projected distinct types.
- **§3.2 / §3.3** — which problems belong to the pin (the `Form.*` duplicate class, already
  converged upstream) and which to the tip (the stream regression, `security: []`, the
  off-convention operationIds, a base64 core shape, two shipped operations deleted upstream).
- **§3.4** — what no refresh will ever fix: brands erased, timestamps reduced to `double`,
  numeric query constraints gone, no discriminator anywhere, and shapes the projection *adds*.
- **§5** — the choice space, unranked on purpose.

**`PostConnectTokenAsync` is currently unusable** and that is a defect this session introduced:
the server requires `x-opencode-ticket: "1"`, no document declares the value, and the SDK has no
header channel. Live-verified: 403 without, 200 with. ADR-0008 reserves exclusion for transports
HTTP cannot carry, so removing the operation is **not** an available answer — it is a plain POST
and the handshake for the hand-written PTY WebSocket client ADR-0008 already anticipates. This
is C1's territory and belongs in the brainstorm.

```sh

git -C external/opencode worktree add --detach .scratchpad/oc-restore origin/v2
```

against the pin.

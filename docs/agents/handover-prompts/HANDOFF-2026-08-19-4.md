## Completed Checkpoint - Arc 3a Closure (`c7a35bd`)

### Generic Host example

- The committed sandbox keeps its standing breadth walkthrough and adds an explicit `--stream`
  mode, which is also the IDE launch-profile default.
- `OpenCode.Sdk.Extensions` registers the singleton root/sub-client family. A hosted worker receives
  `SessionsClient`, creates a session, obtains its bound `SessionClient`, and consumes
  `GetLogAsync(Follow=True, stoppingToken)`.
- Normal host cancellation closes the response read and disposes the container-owned SDK client.
  A worker fault is retained and makes the process return nonzero instead of being hidden by the
  Generic Host's default StopHost behavior.

### End-to-end benchmark

- `SessionLogStreamBenchmarks` calls generated `SessionClient.GetLogAsync` over a canned 200
  `text/event-stream` response, crossing request construction/decorations, `Pipeline`,
  `ServerSentEventReader`, the generated stream adapter, source-generated JSON metadata, and union
  dispatch.
- Global setup refuses the run unless every item materializes as the expected `SessionCreated` or
  `EventLogSynced` generated type and the exact expected frame count is observed. The benchmark
  therefore cannot silently fall onto ADR-0009's unknown carrier after fixture/spec drift.
- BenchmarkDotNet 0.15.8, Ubuntu 26.04/Linux 7.0.0-29-generic, Threadripper 2970WX limited to 12
  cores, .NET SDK 10.0.302, .NET 10.0.10 x64 RyuJIT x86-64-v3, concurrent workstation GC:
  - 64 nested 2,344-byte `SessionCreated` payloads: 1.157 ms/op, 717.82 KB/op.
  - 1,024 shallow 55-byte `EventLogSynced` payloads: 1.674 ms/op, 507.20 KB/op.
- These are complete-response coverage baselines, not causal isolation or an optimization claim.
  Research Q113 records confidence intervals, standard deviations, distribution warnings, framed
  body sizes, setup, and limitations.

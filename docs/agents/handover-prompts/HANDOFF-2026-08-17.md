## Sealed Reset

### Protocol authority and curation (ADR-0013)

- `spec/openapi.json` is the sole protocol-semantic generator input.
- `external/opencode` implementation source is provenance and diagnostic evidence only.
- OpenAPI extensions present in the pin are input when the whitelist admits them.
- Curation may choose .NET names/placement, collapse shapes proven equivalent from OpenAPI, and
  fingerprint exclusions evidenced by the document.
- Curation may not add a type, format, range, cross-field rule, or validation absent from the pin.
- Descriptions become documentation, never executable validation.
- Projection loss stays faithful or fails closed; verified discrepancies go upstream.

Allowed examples: group/client/handle naming, envelope payload names, operation-name overrides,
validated exact schema aliases, and transport exclusions. Forbidden examples: name-derived
`PositiveCount`, `mutuallyExclusiveQueries`, `after -> long?` from Effect source, or `Uri` inferred
without OpenAPI `format: uri`.

### Runtime materialization and ownership (ADR-0014)

- Runtime validates transport/framing, JSON materialization, required .NET shape, and union
  dispatch; it does not replay server schema validation for an already representable value.
- `IsRequired = schema required`.
- `IsNullable = !IsRequired || schema admits null`.
- Required-nullable emits `required T?`, accepts explicit null, and writes the member as null.
- Optional values collapse omission and explicit null to C# null and use `WhenWritingNull`.
- Optional collections are nullable; they do not normalize absence to empty.
- Collections are shallow `init`-only `IReadOnly*` references. No defensive copy, wrapper, empty
  allocation, or recursive item/value validation is emitted. Caller-supplied mutation is caller
  responsibility.
- Item/value nullability remains recursive C# annotation only.
- Union discriminators remain constants because marker dispatch proves them.
- Non-discriminator fixed literals remain ordinary primitive properties; wrong but representable
  server values are preserved rather than rejected or normalized.
- Declared no-content status ignores an unexpected body.
- Buffered JSON decoding stays delegated to `HttpContent` charset/BOM behavior; no one-shot strict
  UTF-8 or single-decoder media-type wall is added. SSE keeps its protocol-specific media,
  framing, size, event-name, truncation, and strict UTF-8 walls.
- `NoThrow` still affects API errors only. Impossible materialization and transport/protocol
  failures throw `OpenCodeTransportException`.

### Fail-closed walls that do not move

- Microsoft.OpenApi parsing plus the whitelist SpecIR projection.
- Unsupported construct, structural-union, hybrid-object, type/name collision, and placement walls.
- Selected/pending profile accounting and fingerprinted transport exclusions.
- Generated manifest ownership, deterministic emission, regen verify, analyzer wall, and public
  API baseline.
- Source-generated System.Text.Json registry and reflection-disabled/Native AOT posture.
- Required-member and non-null top-level response materialization.
- Exact status dispatch and undeclared-success refusal.
- Union marker presence/type dispatch, unknown-variant carriers, and raw unknown-payload lifetime.
- Transport, cancellation, timeout, response ownership, SSE framing, and typed error spine.
- Request null/body guards, URI representability/escaping, and values that cannot map to a declared
  wire token. Server-only ranges and parameter combinations are not local guards.

### Required red matrix

Use one typed synthetic `SpecScenario`, not a fixture dump family, to bind, emit, source-generate,

| Presence | Schema null | Expected C# | Missing | Explicit null | Null write |

| optional | no | `T?` | null | null | omit |

## Six Gates

Every source commit runs exactly:

```bash
set -o pipefail && \
dotnet tool run slopwatch analyze --exclude ".scratchpad/**,external/**" --fail-on warning && \
dotnet build --configuration Release && \
dotnet format --verify-no-changes --no-restore && \
./tools/opencode-tool.cs --help && \

dotnet test --configuration Release --no-build && \
printf 'ALL-GREEN\n'
```

Before committing, inspect status, every changed/new/deleted file, the complete diff, and recent
log; stage only the green increment. Performance-touching commits carry benchmark evidence. Push
directly to `master`, wait for all three hosted OS jobs, and update owning issues before starting
the next increment.

## Stop Conditions

- Any source other than pinned OpenAPI begins supplying protocol semantics.
- Curation adds a type/constraint/format/validation absent from the document.
- A generator/runtime branch names an endpoint, schema, property, client, or generated concrete
  model to implement semantic behavior.
- A representable server value is rejected only because OpenAPI would reject it.
- Required/nullable axes are collapsed, or `WhenWritingNull` reaches a required-nullable member.
- Collection copying/normalization is retained without new measured and maintainer-approved
  ownership evidence.
- Reflection, a converter factory, or unregistered metadata enters product JSON paths.
- Union, unknown-variant, error-spine, SSE framing, or unknown-field decisions are reopened without
  new evidence and maintainer approval.
- Generated output is hand-edited, fixtures are expanded into an unchecked corpus, or fail-closed
  build-time walls are weakened to make the cleanup pass.

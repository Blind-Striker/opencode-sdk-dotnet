## Exact Next Increment - #47

Title: **M3: close StreamPlan binding and emission contracts before event.subscribe**.

#47 is an Arc 3b blocker. It closes the fail-closed stream profile and generic generated-stream
evidence before `v2.event.subscribe` can enter the generation profile. This is a generator/binder
contract increment; no runtime redesign is expected.

### Required behavior

- Require stream-frame `id` to be the declared nullable string shape.
- Require stream-frame `event` to be string.
- Require `x-effect-stream.encoding` to exist and equal `"sse"`.
- Refuse `failureEvent == "message"`; `message` is the ordinary SSE event name, so accepting the
  collision makes every ordinary payload look like a stream failure.
- Refuse body-bearing streams at a located binding wall until the runtime has a body-capable stream
  overload.
- Stream XML documentation must say declared API errors always throw and must never mention
  `NoThrow`; streaming methods deliberately expose no per-call request options (ADR-0007).
- Add generic bind -> emit -> source-generate -> compile evidence for a stream operation. Pin method,
  route, cancellation token, payload/failure metadata, no-options signature, and every declared
  error status/tag.
- Pin selected `session.log` as GET with complete 400/401/404 mappings.

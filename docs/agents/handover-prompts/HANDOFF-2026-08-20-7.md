## Exact Next Increment - Arc 5

Arc 5 is the net472/singleton-owned-transport GA gate from #43. Keep it one bounded cluster because
the mechanisms interact at the real handler and disposal boundary:

1. Disable automatic redirects on every owned-handler path so undeclared 3xx responses reach the
   pipeline and become protocol failures. Do not invent authority/method/credential redirect
   tolerance without a new decision.
2. On net472, avoid process-global defaults when endpoint-scoped `ServicePoint` settings suffice.
   Lift the two-connection ceiling so long-lived SSE calls cannot starve ordinary requests, and set
   connection lease/rotation to the already-sealed modern 120-second pooled lifetime.
3. Add real-handler evidence, not only injected-handler tests: redirect surfacing, at least two
   same-authority live streams plus an ordinary request on net472, observable lease policy, and
   response/content disposal for success, API error, protocol failure, and cancellation.
4. Execute #32 in this cluster: every route value must refuse lone surrogates and oversized inputs
   consistently on every TFM before escaping. Do not weaken existing dot-segment/empty guards.
5. Preserve ADR-0010's public posture: options-only construction, SDK-owned singleton-friendly
   transport, no public `HttpClient`/handler injection, no `IHttpClientFactory` dependency.

## What The Reset Landed

### #54 — pinned OpenAPI is the sole semantic input (`c0003d1`)

- `GenerationCuration` now contains only naming/placement and proven-equivalence sections:
  `groups`, `envelopePayloadNames`, and structurally checked `schemaAliases`.
- `propertyOverrides`, `mutuallyExclusiveQueries`, `PositiveCount`, name-derived `limit` typing,
  and the prose-derived `order`+`cursor` refusal are gone.
- `limit` and `after` remain string-shaped from the pin. The exact `asc`/`desc` enum stays
  `ListOrder`; exact string tokens `true`/`false` use `QueryBoolean`, never a guessed C# `bool`.
- A model property becomes `Uri` only from OpenAPI `format: uri`; the two URI-named properties
  lacking that format are strings. Their narrow CA1056 arbitration names OpenAPI fidelity as the
  winner.
- Query descriptions emit documentation but no guard. Unsupported string enums and formatted query
  shapes fail closed rather than widen silently.
- The selected query shapes, strict curation schema, formatted nested profiles, collision walls,
  generated output, and PublicApi changes are pinned by tests.

Hosted CI: `32069792901`, green on Linux, Windows, and macOS. Issue #54 is closed completed.

### #55 — materialize the .NET shape, with shallow ownership (`e842cdf`)

- `IsRequired` is schema presence. Optional properties use CLR null for absence; at #55,
  schema-null used CLR null at required properties and present collection slots.
- Required-nullable members are `required T?`, accept and write explicit null, and never receive
  `WhenWritingNull`. Optional null and omission collapse and serialize by omission.
- Optional collections are nullable. Every generated collection is a shallow auto `get; init;`
  `IReadOnly*` reference; no copy, wrapper, recursive copy, empty normalization, or child scan
  remains. Caller mutation is caller responsibility.
- `AllowsWireNull`, all `WireNullRejecting*` converters, `OptionalCollectionInput`,
  `NullElementRejectingListJsonConverter`, `ListPayloadInput`, page copies/scans, and no-content body
  refusal are deleted. The generator owns the manifest deletion.
- Union converters leave null handling to outer generated metadata. Collection child nulls are
  annotation-only, while required union properties and top-level response payloads still fail
  materialization through `RespectNullableAnnotations` and adapter/root guards.
- Discriminators, fixed outer markers, unknown carriers/raw replay, strict enums, special-number
  semantics, source-generated metadata, reflection-disabled execution, error-path guarded getters,
  exact status dispatch, and SSE framing remain.
- One typed `MaterializationMatrixScenario` binds, emits, source-generates, compiles, deserializes,
  and serializes required/optional plus nullable/non-null scalar, value, list, dictionary,
  unrestricted, literal, and union shapes.

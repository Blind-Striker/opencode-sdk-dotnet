# M3 Execution Plan — Streams

Date: 2026-08-17

**Goal:** the SDK becomes live: a consumer watches a real session's event stream as typed
events over `IAsyncEnumerable<T>` against `opencode2 serve`. Everything in this milestone
either serves that demo or rides the same runway (milestones are deliverable-first).
Sealed inputs: ADR-0003/0004 and ADR-0007–0014, research doc 02 (SSE:
`IAsyncEnumerable`, no auto-reconnect), doc 15 §5a/§6 (placement census), research log Session 22
and Sessions 24–29, and the standing performance guardrails.

## Arc 2 — Location + merged-Request design session (seals before any body+query admission)

Census: 61 ops carry the optional `location` deepObject
(`location[directory]=…&location[workspace]=…`); all 15 body+query mixes are
location-only; `session.list` alone uses flat fields; ambient
`x-opencode-directory`/`x-opencode-workspace` headers are spec-invisible middleware;
server precedence query > header.

- [x] **Q-A, marshalling (sealed — Q93):** binder-owned per-property placement map — one
      uniform `{Op}Request` whose properties carry body/query/path placement in the
      operation plan; emitters stay name-blind; the body+query double-derivation refusal
      pin retires per-operation as the map admits it. Upstream parity: the first-party
      client emits one uniform `{Op}Input` per operation.
- [x] **Q-B, location rendering (sealed — Q94):** generated `Location` property on the
      request records (the spec-visible channel) plus an ambient default on
      `OpenCodeClientOptions` riding the header channel; an explicit per-request value
      wins by the server's own precedence — no client-side merge. `session.list`'s flat
      fields bind as ordinary query properties, no special case.
- [x] Session output: both seals recorded in the research log (Session 25); the stop
      condition ("no body+query operation admitted without the sealed merged-Request
      design") lifts.

## Arc 3 — SSE

Streaming endpoints **generate** like any other operation (Q96, ADR-0008 as corrected):
the engine is hand-written identity core, the endpoints are one-line delegations into it.
The arc splits because its two operations differ by an order of magnitude in closure —
`session.log` adds 58 schemas over a 2-branch union, `event.subscribe` adds 125 over an
87-branch one — and bringing an engine up should not be entangled with the larger union.

### Arc 3a — the engine, on `v2.session.log`

- [x] Hand-written SSE engine beside the one-shot path: `ResponseHeadersRead` send reusing
      the pipeline's endpoint/auth/location decoration, the undeclared-2xx and non-200
      walls answering before the body is read, a case-insensitive `text/event-stream`
      content-type wall, then the `ServerSentEventReader` collaborator — CRLF
      normalization, `\n\n` boundaries, `data`/`event` field collection, a maximum-frame
      guard, cancellation and disposal. A read failing mid-stream becomes a transport
      failure like any other (ADR-0007), and a frame naming the declared
      `failureEvent` throws instead of deserializing (Q98). It never reuses the one-shot
      buffer, so the Arc 6 perf pass touches this shape once.
- [x] **Stream lifecycle review closure (#39):** recheck disposal when lazy enumeration
      begins, observe cancellation between already-buffered frames, map untouched-token stream
      cancellation onto the transport spine, and prove first-frame delivery before EOF.
- [x] Reject malformed SSE UTF-8 incrementally (#42) without moving either reader allocation
      baseline. Session 29 retires #42's one-shot arm: buffered JSON charset/BOM decoding remains
      delegated to `HttpContent` (ADR-0014).
- [x] Generator core: admit `text/event-stream` responses; recognize the
      `{id, event, data}` frame object structurally; bind the
      **JsonString dialect** (`contentSchema` + `contentMediaType`) so `data` types into
      its payload; emit `IAsyncEnumerable<T>` instead of a response envelope, with no
      per-call options parameter (Q97, ADR-0007), plus the stream adapter carrying the
      declared `failureEvent`.
- [ ] **Complete the fail-closed stream profile (#47):** validate `id`, `event`, `encoding`,
      and the failure-name/payload-name distinction; add stream bind → emit → compile coverage,
      exact verb/token/error-map contract tests, and stream-specific XML documentation.
- [x] Four closure mechanisms the stream operations are the first to reach (doc 15 §5), all
      shared with Arc 3b, ordered cheapest first:
      **(1)** collapse the duplicate union parents through `schemaAliases`
      (`Tool.FileContent1`, then `Tool.Content1`) — curation only;
      **(2)** numeric single-value `enum` as a literal marker (`durable.version`, 40 schemas);
      **(3)** a marked union admitted as a branch of another marked union, which is what
      `SessionLogItem = anyOf[Session.Event.Durable, EventLog.Synced]` is;
      **(4)** the two shapes the wall called structural unions — a struct with no declared
      fields (`Session.Inbox.CompactionPayload`, 12 sites) reads as an object of unspecified
      content, and an `anyOf` whose branches are refinements of one primitive reads as that
      primitive. Both live in the binder, not in ingestion: the session parent filter is the
      same shape as the second, so a projection-time collapse would erase a sealed design.
- [x] `Microsoft.Bcl.AsyncInterfaces` is declared and pinned directly, on the two targets
      that need it: `IAsyncEnumerable<T>` is a BCL type from net8.0 on, and only
      `netstandard2.0`/`net472` were resolving it through `System.Text.Json`'s graph. The
      streaming surface returns it publicly, so the dependency is ours to state.
- [x] Preserve named special-number semantics through the generic bound type and emitter (#41):
      finite numbers and exactly `"NaN"`, `"Infinity"`, and `"-Infinity"` round-trip under
      source-generated metadata; arbitrary numeric strings remain unrepresentable. Session 29
      supersedes only the optional-null rejection arm (ADR-0014).
- [x] **Protocol-authority cleanup (#54, ADR-0013):** remove behavior-premised curation and
      name-derived wire semantics, including the #28 mutual-exclusion row, `PositiveCount`,
      format guesses, and #40's planned `after -> long?` override. Keep names/placement,
      validated equivalent aliases, and fingerprinted exclusions. Regenerate and review every
      resulting public type from the pinned OpenAPI alone.
- [ ] **Materialization/ownership cleanup (#55, ADR-0014):** retire #45/#48 as specified; remove
      optional-null converters, collection-child/page scans, empty normalization, defensive model
      copies/wrappers, and non-discriminator literal validation. Emit the required/nullable matrix
      mechanically, preserve discriminators and special-number materialization, review the public
      nullable diff, and benchmark against `050b4f8`.
- [ ] **Known-object policy (#46):** make additive unknown-field skipping explicit, retain typed
      pure dictionaries, and keep the fail-closed named-object plus typed-additional-properties
      wall. This remains compatible with ADR-0013/0014.
- [ ] `follow` and `after` remain faithful to their pinned OpenAPI query schemas. The SDK performs
      no automatic resume, and SSE `id:` is not the cursor. Upstream's hidden numeric `Event.Seq`
      transform belongs to the projection-fidelity audit, not local curation (#40/Q107).
- [ ] Mid-stream Effect failure causes type against `x-effect-stream.causeSchema`. The
      engine already refuses the failure frame rather than yielding it (Q98); what remains
      is reading the cause into a typed shape instead of carrying it as text, including the
      typed-applicator ingestion wall from #53.
- [ ] **Evidence honesty (#49):** keep the runtime corpus representative and schema-valid;
      prove exhaustive converter tags, source-generated registrations, and plural-interface
      membership mechanically. Promote observed frames rather than inventing 40/87 payloads.
- [x] **Demo (2026-08-17, partial by the server's limit):** the stream opens against a live
      `opencode2 serve`, frames decode, and the watermark types as `EventLogSynced`. The
      default server advances durable sequence state without persisting historical payload
      rows (research doc 02). Live breadth still moves to Arc 3b.

### Arc 3b — `v2.event.subscribe`

- [ ] Breadth over the proven engine and the Arc 3a mechanisms: the global bus exposed as
      `Events.SubscribeAsync` through reason-bearing operation-name curation (#44), no
      parameters, no resume. Admits the 87-branch `V2Event` union and its 125 new schemas;
      unknown variants ride the ADR-0009 carriers. It reaches the same four closure
      mechanisms as `session.log` but 16 empty-struct/refinement sites against 2, which is
      the density Arc 3a's ordering exists to avoid paying first. Confirm the event-stream
      media-type and completed stream-profile walls report on this operation too — they did
      not surface in the 2026-08-16 admission probe, where the schema walls answered first.
- [ ] The fifth mechanism, and the reason ADR-0011 landed before the first stream generated:
      39 of `Session.Event.Durable`'s 40 branches are also direct `V2Event` branches, so the
      same leaf belongs to both stream unions. Interface membership is what makes that
      expressible; the wall to add with it refuses two parents declaring markers of the same
      name and different kind. Emission, compilation, source-generated registration, and
      deserialization through both sibling interfaces are one mechanical test chain (#49).
- [ ] **Demo:** watch the live global event stream.

## Arc 6 — The deliberate performance pass (#23-anchored, last on the runway)

- [ ] One pass, after the SSE buffering shape exists (earlier is double work): P1
      single-pass union dispatch (reader-based known-tag path; DOM kept for unknown
      carriers), success-path byte/stream adapters where measurement justifies them (ADR-0007
      `RawBody` stays on the error path), and remaining cursor/DOM copies after the ADR-0014
      cleanup. Closes #23 and #29.
- [ ] The #23 success handoff keeps one-shot bodies inside the overall timeout budget and proves
      response ownership on every exit. Buffered JSON continues through `HttpContent` charset/BOM
      decoding and does not gain a stricter UTF-8 or single-decoder media-type wall; SSE retains
      its protocol-specific media/framing/UTF-8 checks.
- [ ] #33 executes inside the converter rewrite as sealed: carrier constructors refuse
      tag/payload disagreement; `Write` stays payload-only verbatim replay.
- [ ] Before M5 freezes the public surface, benchmark direct `IReadOnlyList` /
      `IReadOnlyDictionary` generated properties against `ImmutableArray` /
      `ImmutableDictionary` for source-generated JSON, Native AOT, netstandard2.0/net472,
      request ergonomics, and allocation/throughput. `FrozenDictionary` is a read-heavy
      long-lived comparison control, not the default DTO candidate (Q108).
- [ ] All under `MemoryDiagnoser`, allocation-first, before/after numbers in the PR.
      Interim discipline: the baselines must not regress through earlier arcs —
      compare against an untouched `050b4f8` checkout under the same SDK/runtime. Reference
      allocations are `GetMessageAsync` 25.93 KB, `ListMessagesAsync` 26.68 KB,
      `GetHealthAsync` 2.08 KB,
      `DeserializeDeepAssistantMessage` 17.37 KB, `ReadLargeFrames` 321.54 KB over 64
      large frames, `ReadSmallFrames` 177.69 KB over 1024 small ones. Allocation is the
      figure that holds; the timings move with machine load. The two frame-reader arms
      exist because the reader has a per-character cost and a per-frame cost that a single
      payload size cannot separate, and a live feed carries mostly small frames.
- [ ] Per-TFM check on the frame reader's data append. `StringBuilder.Append(StringBuilder,
      int, int)` exists from netstandard2.1, so `netstandard2.0` and `net472` compile
      Polyfill's shim, whose body is `Append(value.ToString(), startIndex, count)` — the
      whole line materializes as a string on those two targets. Measurements above are
      net10.0. Closing the gap means a per-TFM path, which belongs in this pass rather than
      earlier.

## Boundaries and stop conditions

The standing list carries: pinned OpenAPI as the sole protocol-semantic input, curation that never
enriches it, opencode-dialect-only fail-closed projection for unsupported shapes, name-blind
emitters, no body+query admission before Arc 2 seals, Extensions dependencies inside research doc
06's policy, no stream design bypassing this plan, no SDK hot-path optimization outside Arc 6,
and no performance claim without benchmark numbers. Runtime materialization walls stay strict
where C# or protocol dispatch requires them but do not become a second server-schema validator
(ADR-0013/0014). Under ADR-0010, no transport-injection or composition-seam surface returns
without the ADR's reversal trigger.

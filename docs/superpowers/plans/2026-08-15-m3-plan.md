# M3 Execution Plan — Streams

Date: 2026-08-15

**Goal:** the SDK becomes live: a consumer watches a real session's event stream as typed
events over `IAsyncEnumerable<T>` against `opencode2 serve`. Everything in this milestone
either serves that demo or rides the same runway (milestones are deliverable-first).
Sealed inputs: ADR-0008/0009/0010, research doc 02 (SSE: `IAsyncEnumerable`, no
auto-reconnect), doc 15 §5a/§6 (placement census), research log Sessions 22 (Q88) and 24
(Q92, #28/#32/#33 seals), the standing performance guardrails.

## Arc 1 — Construction & transport reshape (Q92, ADR-0010; own PR, first on the runway)

- [x] The `(HttpClient, options)` constructor internalizes; IVT covers the repository's
      tests and benchmarks (contract tests and `ContractScenario` keep compiling
      unchanged).
- [x] `Pipeline` keeps its internal ownership flag for the injected test path; the
      anonymous-mode `Authorization` refusal and injected `BaseAddress` refusal delete
      with their tests (the Q90 password semantics — `null` anonymous, blank refused —
      stay pinned).
- [x] Extensions rebuilds factory-less: `AddOpenCode` registers one singleton root client
      over the owned transport, sub-clients resolve from that same instance, the return
      type becomes `IServiceCollection`, and `Microsoft.Extensions.Http` leaves the
      dependency set.
- [x] The roster contract test (from #31): every generated client family resolves through
      DI; the next family cannot silently lag the registration list.
- [x] PublicApi baseline re-review (constructor removal, Extensions signature) and the
      sandbox showcase update. Closes #31.

## Arc 2 — Location + merged-Request design session (seals before any body+query admission)

Census: 61 ops carry the optional `location` deepObject
(`location[directory]=…&location[workspace]=…`); all 15 body+query mixes are
location-only; `session.list` alone uses flat fields; ambient
`x-opencode-directory`/`x-opencode-workspace` headers are spec-invisible middleware;
server precedence query > header.

- [ ] **Q-A, marshalling (recommended):** binder-owned per-property placement map — one
      uniform `{Op}Request` whose properties carry body/query/path placement in the
      operation plan; emitters stay name-blind; the body+query double-derivation refusal
      pin retires per-operation as the map admits it. Upstream parity: the first-party
      client emits one uniform `{Op}Input` per operation.
- [ ] **Q-B, location rendering (recommended):** generated `Location` property on the
      request records (the spec-visible channel) plus an ambient default on
      `OpenCodeClientOptions` riding the header channel; an explicit per-request value
      wins by the server's own precedence — no client-side merge. `session.list`'s flat
      fields bind as ordinary query properties, no special case.
- [ ] Session output: both seals recorded in the research log; the stop condition ("no
      body+query operation admitted without the sealed merged-Request design") lifts.

## Arc 3 — SSE engine

- [ ] Hand-wired stream endpoints per ADR-0008, fingerprint-pinned: `v2.event.subscribe`
      (global, no resume parameters) and `v2.session.log` (`after` + `follow`,
      experimental path). `IAsyncEnumerable<T>`, no auto-reconnect; unknown event
      variants ride the ADR-0009 carriers.
- [ ] Re-derive the durable-stream/resume position against `session.log` — the v1 design
      does not carry over; resume guarantees are unestablished, and "no resume contract
      yet" is a valid seal. Owns the ROADMAP open question.
- [ ] The stream path gets its own read loop and never reuses the one-shot buffer — the
      buffering shape lands here so the Arc 6 perf pass touches it once.
- [ ] **Demo:** watch a real session's event stream live against `opencode2 serve`.

## Arc 4 — Paginator

- [ ] Over the `ListRequest` seam and `ListCursor`. The public shape
      (`AsyncPageable`-like vs plain `IAsyncEnumerable<T>` + per-page access) goes to the
      maintainer with a short ecosystem survey before emission; honors #28's sealed
      order+cursor exclusivity on message-list.

## Arc 5 — net472 cluster (GA gate)

- [ ] `ServicePointManager` connection-lease hardening on the owned transport — under
      the ADR-0010 singleton posture this is what makes a long-lived client correct on
      net472; promoted to a GA gate.
- [ ] #32 executes as sealed: uniform route-boundary refusal (lone surrogates, oversize)
      with a typed `ArgumentException` on every TFM before escaping.

## Arc 6 — The deliberate performance pass (#23-anchored, last on the runway)

- [ ] One pass, after the SSE buffering shape exists (earlier is double work): P1
      single-pass union dispatch (reader-based known-tag path; DOM kept for unknown
      carriers), P3/V28 success-path UTF-8/stream adapters (ADR-0007 `RawBody` stays on
      the error path), V29 internal-handoff copy elision (ADR-0004 defensive copy stays
      for consumers), the cursor-list re-copy. Closes #23 and #29.
- [ ] #33 executes inside the converter rewrite as sealed: carrier constructors refuse
      tag/payload disagreement; `Write` stays payload-only verbatim replay.
- [ ] All under `MemoryDiagnoser`, allocation-first, before/after numbers in the PR.
      Interim discipline: the baselines (`GetMessageAsync` 56.2 μs; `ListMessagesAsync`
      58.1 μs / 28.24 KB) must not regress through earlier arcs.

## Boundary chores

- [ ] Spec-pin refresh is sanctioned at this boundary (`spec/SNAPSHOT.md` procedure,
      submodule pointer in lockstep) — executed after Arc 2's seals so the design lands
      against a stable target; the refresh diff and census deltas ride their own review.
- [ ] Remaining M2 breadth batches interleave after Arc 1 lands, each against the sealed
      marshalling design.

## Boundaries and stop conditions

The standing list carries: opencode-dialect-only, fail-closed on unsupported shapes,
name-blind emitters, no body+query admission before Arc 2 seals, Extensions dependencies
inside research doc 06's policy, no stream design bypassing this plan, no SDK hot-path
optimization outside Arc 6, and no performance claim without benchmark numbers. New under
ADR-0010: no transport-injection or composition-seam surface returns without the ADR's
reversal trigger.
